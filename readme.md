# Network GUI

This program connects the client program to the server program on the localhost, allowing each to send messages to the other through an intuitive GUI.

## Instructions for Build and Use

Steps to build and/or run the software:

1. run the message\_exchange\_gui\_server.py file first.
2. run the message\_exchange\_guy\_client.py file separately.



Instructions for using the software:

1. Once both are running, type a message into the text box at the bottom of the window
2. click "send"
3. Look to the other window and notice a message has appeared. 
4. Know that this works both ways.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Python3
* tkinter module installed
* socket and threading python modules
